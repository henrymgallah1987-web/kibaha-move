# KibahaMove

A multimodal transport planning system for Kibaha, Tanzania.

## Problem
Passengers may struggle to find reliable routes, fares, availability, and travel-time information for trains, buses, daladalas, bajaji, pikipiki, and taxis.

## Goal
Help passengers compare transport options and plan trips from one location to another.

## Users
- Passengers
- Drivers and transport operators
- System administrators

## MVP Features
- Search routes by origin and destination
- Show available transport modes
- Display estimated fares and travel times
- Show stops and stations
- Let operators update transport availability

## Technology Plan
- Frontend: React
- Backend: Python with FastAPI
- Database: PostgreSQL
- Maps: OpenStreetMap
